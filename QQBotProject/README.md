# 典狱长群服管理中心 (v1.2) - 快速上手手册

欢迎使用 **典狱长群服管理中心**！本工具专为传奇（Mir2）版本开发者与群管理设计，集成了机器人自动办公、版本脚本智能植入、CDK 销售、积分系统及授权解码等功能。

---

## 🚀 1. 快速入手

### 1.1 环境准备
1. **安装 Python**: 建议使用 Python 3.8+。
2. **安装依赖**: 在工程根目录执行以下命令：
   ```bash
   pip install -r requirements.txt
   ```
   *注意：如果缺少 `requirements.txt`，请手动安装核心库：`pip install websockets dataset pycryptodome sqlalchemy`。*
3. **启动程序**: 运行 `main.py` 即可打开管理界面。

### 1.2 机器人连接 (LLOneBot)
本机器人通过 WebSocket 连接到 **LLOneBot**。
1. 在 LLOneBot 的设置中开启 **正向 WebSocket 服务**。
2. 在管理界面左上角输入连接地址（例如 `ws://127.0.0.1:3001`）和 Token。
3. 点击 **[启动]**，若日志显示 `LLOneBot 连接成功！`，则机器人已上线。

## 🛠️ 2. 功能配置与管理

### 2.1 区服与账号绑定
*   **绑定文件**: 在“同步目录设置”中指定一个 `.txt` 文件作为注册记录数据库。
*   **管理区服**: 在界面中间的“区服管理”列表中添加您的游戏区名（如：`热血传奇二区`）。
*   **清理无效记录**: 点击 **[扫]** 按钮，系统会自动删除已在列表中移除的区服对应的注册记录。

### 2.2 CDK (卡密) 管理系统
*   **原理**: 机器人销售 CDK -> 写入版本 `未使用CDK.txt` -> 玩家在游戏内兑换 -> 游戏生成 `已使用.txt` 日志 -> 机器人读取并同步数据库。
*   **配置路径**: 
    *   **未使用**: 指向版本 `Mir200\Envir\QuestDiary\典狱长功能\未使用CDK.txt`。
    *   **已使用**: 指向版本生成的已使用日志文件。
*   **自动同步**: 机器人启动后会实时监控日志并更新数据库中的 CDK 状态。

## 📝 3. 脚本模板与语法 (核心)

工程使用 `Mir2Text` 目录下的文件作为模板。

### 3.1 变量语法
在模板文本中，使用 `*变量名*` 或 `*变量名=默认值*` 的格式。
*   **示例**: `S1.赋予称号 *称号名称=无敌战神*`
*   **UI 刷新**: 在界面点击 **[刷新变量]**，系统会自动扫描 `Mir2Text` 下所有文件，并在“注入变量”列表中列出这些变量。您可以在界面直接输入值，无需修改模板文件。

### 3.2 智能植入协议 (Smart Implant)
为了不破坏您的原版脚本，我们在 `QF.txt` 和 `QM.txt` 中支持特殊标记：

*   **追加模式**: 默认将内容写到文件末尾。
*   **植入模式**: `;=== 植入@Login=描述开始 ===` 会寻找目标文件的 `[@Login]` 段落并在其头部插入内容。
*   **覆盖模式**: `;=== 覆盖@Help=描述开始 ===` 会直接替换掉目标文件中整个 `[@Help]` 段落。

## 🏗️ 4. 写入到版本 (一键同步)

1. **选择版本目录**: 点击“选择版本目录”，指向您的版本根目录（包含 `Mir200` 的文件夹）。系统会自动识别 `Config.ini` 中的游戏名。
2. **刷新并输入**: 点击 **[刷新变量]**，在列表中填写本次开区需要修改的参数（如积分倍率、NPC 名称等）。
3. **一键写入**: 点击 **[写入功能]**。
    *   系统会自动将 `QF.txt` 注入到 `QFunction-0.txt`。
    *   将 `QM.txt` 注入到 `QManage.txt`。
    *   将 `典狱长.txt` 复制到 `Market_Def` 目录。
    *   将 `典狱长功能` 文件夹内的所有扩展脚本同步到 `QuestDiary\典狱长功能`。

## 🤖 5. 群服管理指令

机器人开启“群管理”开关后，支持以下指令：

| 分类 | 指令 | 说明 | 权限 |
| :--- | :--- | :--- | :--- |
| **基础** | `菜单` / `功能` | 查看所有指令列表 | 所有人 |
| **注册** | `开区列表` | 查看当前所有开区 | 所有人 |
| **注册** | `绑定 [区号] [账号]` | 注册游戏账号 | 所有人 |
| **积分** | `签到` | 每日打卡获得积分 | 所有人 |
| **CDK** | `购买CDK [价格]` | 消耗积分购买卡密 | 所有人 |
| **管理** | `加黑/拉黑 [QQ]` | 加入黑名单，巡逻模式下自动踢出 | 管理员 |
| **管理** | `新增CDK [数量] [价格]` | 批量生成 CDK | 群主 |
| **高级** | `反查 [账号]` | 通过游戏账号查询绑定的 QQ | 群主 |

## 🔍 6. 调试与常见问题

*   **日志窗口**: 右侧的“运行日志”会记录所有 WebSocket 交互和脚本注入过程中的错误。
*   **编码问题**: 本工程默认使用 `GB18030` (兼容 GBK) 处理传奇脚本，如果遇到乱码，请确保您的 `.txt` 模板不是 `UTF-8` 无 BOM 格式。
*   **权限错误**: 如果写入失败，请检查版本文件是否被游戏引擎（M2Server）占用，建议先关闭 M2 再写入。
*   **机器人不理人**: 检查“群功能开关”是否已勾选，并确保机器人在群里拥有管理员权限（如果是撤回指令）。
